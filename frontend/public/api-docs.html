Base URL: http://localhost:52106 (直接访问) 或 /api (通过前端代理)

  }

GET /api/hot100/online-counts/:id
获取指定问题的历史在线人数（支持 CN/COM/Total 三站数据）
id (path) 必填 - 问题 ID（支持数字 ID 或 slug，如 "1" 或 "two-sum"）
limit (query) - 返回记录数量，默认 100
site (query) - 数据来源: "cn", "com", "unified", "all"（默认 "all"）
响应示例 (site=all):
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "timestamp": "2025-01-15T10:30:00Z",
      "count_cn": 800,
      "count_com": 450,
      "count": 1250
    },
    {
      "timestamp": "2025-01-15T10:25:00Z",
      "count_cn": 780,
      "count_com": 430,
      "count": 1210
    }
  ]
}

GET /api/hot100/export
导出数据（支持 JSON 和 CSV 格式）
format (query) - 导出格式: "json" 或 "csv"，默认 "json"
problem_id (query) - 指定题目 ID（可选）
start_date (query) - 开始日期 (YYYY-MM-DD)
end_date (query) - 结束日期 (YYYY-MM-DD)
site (query) - 数据来源: "cn", "com", 或空（unified）
响应示例 (format=json):
{
  "exported_at": "2025-01-15T10:30:00Z",
  "count": 500,
  "data": [
    {
      "id": 1,
      "frontend_id": "1",
      "count_cn": 800,
      "count_com": 450,
      "count_total": 1250,
      "timestamp": "2025-01-15T10:30:00Z"
    }
  ]
}

历史数据查询

GET /api/history
通过查询参数获取题目历史在线人数
problemId (query) 必填 - 问题 ID 或 slug
hours (query) - 查询时间范围（小时），默认 24
limit (query) - 返回记录数量，默认 1000
site (query) - 数据来源: "cn", "com", "unified", "all"
startDate (query) - 开始日期 (YYYY-MM-DD 或 YYYY-MM-DD HH:mm:ss)
endDate (query) - 结束日期 (YYYY-MM-DD 或 YYYY-MM-DD HH:mm:ss)
响应示例:
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "timestamp": "2025-01-15T10:30:00Z",
      "count_cn": 800,
      "count_com": 450,
      "count": 1250
    }
  ]
}
GET /api/total-online-history
获取总在线人数历史数据（包含 CN/COM/Total 三站数据）
hours (query) - 查询时间范围（小时），默认 24，最大 168
响应示例:
{
  "code": 200,
  "msg": "success",
  "data": {
    "hours": 24,
    "points": 1440,
    "data": [
      {
        "timestamp": "2025-01-15T10:30:00Z",
        "total": 45000,
        "cn": 28000,
        "com": 17000
      },
      {
        "timestamp": "2025-01-15T10:29:00Z",
        "total": 44800,
        "cn": 27800,
        "com": 17000
      }
    ]
  }
}
GET /api/total-online-aggregate
获取聚合的总在线人数数据（支持分钟/小时/天粒度）
granularity (query) - 时间粒度: "minute", "hour", "day"，默认 "minute"
start (query) - 开始时间 (RFC3339 格式，如 2024-01-01T00:00:00Z)
end (query) - 结束时间 (RFC3339 格式)
site (query) - 数据来源: "cn", "com", "unified"，默认 "unified"
响应示例 (granularity=hour):
{
  "code": 200,
  "msg": "success",
  "data": {
    "granularity": "hour",
    "start_time": "2025-01-14T10:00:00Z",
    "end_time": "2025-01-15T10:00:00Z",
    "points": 24,
    "data": [
      {
        "timestamp": "2025-01-15T10:00:00Z",
        "total": 45000
      },
      {
        "timestamp": "2025-01-15T09:00:00Z",
        "total": 42000
      }
    ]
  }
}

兼容端点 (Legacy)

GET /api/problems
获取问题列表 (同 /api/hot100/problems)
GET /api/online-counts/:id
获取历史在线人数 (同 /api/hot100/online-counts/:id)
GET /api/online-counts/latest
获取最新在线人数 (同 /api/hot100/online-counts/latest)

WebSocket

ws://localhost:52106/ws
WebSocket 实时推送端点，用于接收实时在线人数更新
消息格式示例:
{
  "type": "online_update",
  "timestamp": "2025-01-15T10:30:00Z",
  "data": [
    {
      "frontend_id": "1",
      "slug": "two-sum",
      "online_count_cn": 800,
      "online_count_com": 450,
      "online_count_total": 1250
    }
  ]
}

错误响应格式

所有 API 在发生错误时返回统一格式
错误响应示例:
{
  "code": 404,
  "msg": "Problem not found",
  "data": null
}
